- 页面组件以默认导出函数形式定义（`export default function Home()`），符合 Next.js App Router 的页面约定。
- UI 文案与数据（steps、features、faqs）以模块级常量数组声明，再在 JSX 中通过 `.map()` 渲染，保持内容与结构分离。
- 样式全部使用 Tailwind 原子类，内联 className 字符串，不单独为组件编写 CSS 文件。
- 图标统一从 `lucide-react` 导入并以组件形式传入（如 `<ArrowRight />`、`<step.icon />`），保持图标风格一致。
- 响应式布局通过 Tailwind 前缀（`sm:`、`lg:`）实现移动端优先的断点适配。
