采用 Next.js App Router 约定式路由：`app/layout.tsx` 作为根布局，通过 `next/font/google` 注入 Geist Sans/Mono 字体变量，并导出全局 Metadata（标题与描述）；`app/page.tsx` 作为根路径 `/` 的页面组件，组合 `SiteHeader` 和 `RagDemoChat` 两个子组件，以纯函数组件形式渲染 Landing Page 的各个 section（Hero、Use Case、Features、FAQ、CTA、Footer）。样式通过 `app/globals.css` 引入 Tailwind v4（`@import "tailwindcss"`），并在 `@theme inline` 中声明 CSS 自定义属性映射到 Tailwind 语义化 token（如 `--font-sans`、`--color-background`），实现字体与主题色的集中管理。依赖方向单向：页面 → 子组件 → lucide-react 图标，无反向引用。
